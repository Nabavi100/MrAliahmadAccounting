# سیستم حسابداری شرکت تجارتی برادران نبوی

سیستم جامع حسابداری دو ارزی (افغانی و دالر)، خرید و فروش، مدیریت گدام و گدام امانی،
صرافی، طلبات و بدهیات، هزینه‌ها و عواید، دارایی‌های ثابت و سهامداران.

---

## اجرای برنامه

```bash
npm install       # نصب پکیج‌ها
npm run dev       # اجرای برنامه روی پورت ۳۰۰۰ (حالت توسعه)
npm run build     # ساخت نسخه نهایی در پوشه dist
npm start         # اجرای سرور (تولید)
```

| اسکریپت | کاربرد |
| --- | --- |
| `npm run dev` | اجرای برنامه همراه با سرور تلگرام |
| `npm run build` | ساخت نسخه تولیدی |
| `npm run typecheck` | بررسی کامل تایپ‌های TypeScript |
| `npm run smoke` | تست خودکار رندر (بدون نیاز به مرورگر) |

> **نکته:** برنامه در حالت توسعه روی `0.0.0.0` گوش می‌دهد و آدرس‌های پروکسی/پیش‌نمایش را می‌پذیرد،
> بنابراین از طریق شبکه داخلی یا اینترنت (تانل) نیز قابل دسترسی است.

## میان‌بُرهای کیبورد

برای کار سریع‌تر، بدون استفاده از ماوس:

| کلید | عملکرد |
| --- | --- |
| `Ctrl + K` (یا `⌘ + K`) | جستجوی سراسری و اجرای سریع دستورات |
| `Ctrl + B` | باز و بسته کردن منوی کناری |
| `Alt + 1` … `Alt + 9` | رفتن به داشبورد، روزنامچه، فاکتورها، دریافت/پرداخت، مشتریان، گدام‌ها، صندوق‌ها، گزارش‌ها، تعاریف |
| `Alt + N` | فاکتور فروش جدید |
| `Alt + M` | فاکتور خرید جدید |
| `Alt + R` | رسید دریافت وجه |
| `Alt + P` | سند پرداخت وجه |
| `Alt + T` | انتقال کالا بین گدام‌ها |
| `Alt + S` | مدیریت کاربران و سطوح دسترسی |
| `Alt + H` | راهنمای همین میان‌بُرها |

میان‌بُرها بر اساس **کد فیزیکی کلید** کار می‌کنند، پس با کیبورد فارسی/دری هم درست عمل می‌کنند،
و هنگام تایپ داخل فرم‌ها به‌طور خودکار غیرفعال می‌شوند.

## جستجوی سراسری (Ctrl + K)

یک پنجره واحد که همزمان در موارد زیر جستجو می‌کند:

- **صفحات و بخش‌ها** — رفتن سریع به هر صفحه سیستم
- **عملیات** — صدور فاکتور، رسید، پرداخت، انتقال وجه، تبدیل ارز، پشتیبان‌گیری و…
- **طرف حساب‌ها** — با نام، شماره تماس، کد یا گروه (کارت حساب مستقیماً باز می‌شود)
- **کالاها** — با نام، کد یا گروه همراه با موجودی فعلی (کارتکس کالا باز می‌شود)
- **فاکتورها** — با شماره فاکتور، نام طرف حساب یا تاریخ

جستجو با حروف فارسی و عربی، اعداد فارسی و لاتین و حتی با کمی غلط تایپی کار می‌کند.

## استفاده در موبایل و تبلت

- منوی کناری در موبایل به‌صورت کشویی (Drawer) باز می‌شود و با انتخاب هر گزینه خودکار بسته می‌شود.
- نوار پائین صفحه چهار بخش پرکاربرد (داشبورد، فاکتورها، دریافت/پرداخت، گزارش‌ها) به‌همراه
  دکمه «+» برای عملیات سریع و جستجو را در اختیار می‌گذارد.
- جدول‌ها در صفحه‌های کوچک به‌صورت افقی قابل اسکرول هستند.
- صفحه‌ای که آخرین بار باز کرده‌اید، در مراجعه بعدی مستقیماً باز می‌شود.

## کارایی

صفحات سنگین (گزارش‌ها، داشبورد، نمودارها و پنجره‌های چاپ) به‌صورت **بارگذاری تنبلی (Lazy)** جدا شده‌اند؛
حجم بار اولیه از حدود ۶۵۹ کیلوبایت به حدود ۱۴۷ کیلوبایت (gzip) کاهش یافته و بقیه فقط در صورت
نیاز دانلود می‌شود — که روی اینترنت موبایل و شبکه‌های کند تفاوت محسوسی دارد.

## نگهداری اطلاعات

> ⚠️ **مهم:** تمام اطلاعات حسابداری در حال حاضر در حافظه مرورگر همان دستگاه
> (`localStorage`) ذخیره می‌شود. یعنی:
> - اگر حافظه مرورگر پاک شود، اطلاعات هم پاک می‌شود؛
> - از یک دستگاه دیگر (مثلاً موبایل) همان اطلاعات دیده **نمی‌شود**.
>
> برای دسترسی چند دستگاهی لازم است داده‌ها به بانک اطلاعاتی سرور منتقل شود.
> تا آن زمان، حتماً از بخش «پشتیبان‌گیری» (فایل JSON یا گوگل درایو) به‌طور منظم بکاپ بگیرید.
